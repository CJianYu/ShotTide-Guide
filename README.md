# ShotTide Product Guide

[ShotTide](https://shottide.com/) is a browser-based creative studio for AI storyboards, images, video, and voiceover. This repository provides a short guide to its public creative workflows.

## Start with the result you want

| Your task | Where to start |
| --- | --- |
| Turn an idea into an editable shot plan | [AI Storyboard](https://shottide.com/ai-storyboard-generator) |
| Generate a video from a written prompt | [Text to Video](https://shottide.com/ai-video-generator) |
| Use an existing image as a video starting point | [Image to Video](https://shottide.com/image-to-video) |
| Explore a visual concept or create a reference image | [AI Image](https://shottide.com/ai-image-generator) |
| Add spoken narration to a project | [AI Voiceover](https://shottide.com/ai-voiceover) |

For a first project, follow the [quickstart](QUICKSTART.md).

## Working with a storyboard

Start with a brief that describes the subject, intended audience, visual mood, and sequence. ShotTide's public workflow describes planning 2-6 editable shots, refining their prompts, and generating images or video for individual scenes.

The canvas keeps shot prompts, ordering, and versions together. Review the project assistant's suggestions before applying them. Choose the version you want for each shot, add narration if needed, and export an MP4. Voiced exports can include an accompanying captions file.

## Other studio workspaces

- **Drama Studio:** develop characters, locations, and props, plan a short series, and turn episodes into editable production projects.
- **Model Board:** generate images, video, voices, and avatar clips, compare supported models with the same input, and retain results in the asset library.
- **3D Shot Composer:** place characters and props, adjust framing and perspective, and use the rendered composition as a generation reference.

Open the workspaces from [ShotTide](https://shottide.com/).

## Pricing and access

ShotTide uses credits for generation and offers subscriptions and credit purchases. Required credits vary by model and task; generations are not unlimited. Editing, uploads, and downloads are included according to the public pricing page.

Check [current plans and credit costs](https://shottide.com/pricing) before starting a paid generation. This guide does not duplicate prices or promise a free generation allowance.

## Languages

The website provides [English](https://shottide.com/) and [Chinese](https://shottide.com/zh) interfaces.
